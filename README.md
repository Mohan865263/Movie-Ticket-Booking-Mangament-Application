# Movie Ticket Booking Management Application

## 📌 Project Overview

The Movie Ticket Booking Management Application is a Pega-based application designed to simplify the process of searching movies, selecting shows, booking tickets, managing bookings, and cancelling tickets.

## 🎯 Objectives

- Provide an easy movie ticket booking process
- Allow users to select movies and show timings
- Manage ticket bookings efficiently
- Support booking cancellation
- Reduce manual booking processes
- Provide a user-friendly application experience

## 🛠️ Technology Used

- Pega Platform
- Pega App Studio
- Case Management
- Decision Tables
- Workflows
- UI Forms
- Business Rules

## 🔄 Main Features

- Movie Selection
- Show Time Selection
- Seat/Ticket Selection
- Ticket Booking
- Booking Confirmation
- Booking Cancellation
- Booking Status Management

## 📋 Project Workflow

1. User selects a movie
2. User selects date and show time
3. User enters booking details
4. System validates the request
5. Ticket booking is processed
6. Booking confirmation is generated
7. User can cancel the booking when applicable
